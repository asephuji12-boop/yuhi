Import / Export Santri

Kolom Excel: No, ID, Nama, Alamat, Kelas, Kamar. ID wajib diisi — baris tanpa ID akan dilewati. Jika ID sudah ada di data, santrinya diperbarui (bukan dobel).

Import / Export Absen

Berlaku untuk Program & Tanggal yang dipilih di tab Alfa. Kolom Excel: No, ID, Nama, Kelas, Status (isi "Hadir", "Alfa", "Sakit", atau "Izin"). Pencocokan baris memakai kolom ID — baris tanpa ID tidak akan cocok dengan santri manapun. Setelah import, buka tab Alfa lalu tekan Simpan Absen untuk menyimpan ke server.

Import / Export Pulang

Kolom Excel: No, ID, Nama, Kelas, Mulai, Selesai, Keterangan. Tanggal format YYYY-MM-DD. Pencocokan baris memakai kolom ID — baris tanpa ID tidak akan cocok dengan santri manapun.

Backup / Restore Semua Data

Export menyimpan seluruh data (santri, absen, izin) dalam satu file .json sebagai cadangan lengkap. Import akan menimpa semua data yang sedang ada di aplikasi dengan isi file cadangan tersebut.

Hapus Semua Data

Menghapus seluruh data santri, absen, dan izin dari aplikasi (mulai dari nol). File Excel yang sudah pernah diexport tidak ikut terhapus, karena tersimpan terpisah di perangkat Anda. Sebaiknya lakukan Export Semua Data dulu sebelum menghapus.
